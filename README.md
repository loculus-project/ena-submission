# ENA Submission - Approved Sequences Repository - Loculus Testing

This is a copy of https://github.com/pathoplexus/ena-submission for testing ENA submission on Loculus. 

Link to this repo by adding the following lines to your values.yaml: 

```
enaDeposition: 
  enaApprovedListTestUrl: "https://raw.githubusercontent.com/loculus-project/ena-submission/main/approved/approved_ena_submission_list.json"
```
